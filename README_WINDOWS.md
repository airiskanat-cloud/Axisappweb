### **1. Площадь и периметр ✅**
**Проблема:** Неверный расчет
**Решение:** 
```python
# БЫЛО:
area = W * H / 1_000_000  # без учета количества

# СТАЛО:
area = (W * H / 1_000_000) * count  # с учетом количества!
perimeter = (2 * (W + H) / 1000) * count
```

**Проверка на данных из чертежа:**
- Ожидается: **66.3 м²** и **122.2 м.п.**

### **4. Световой проем - ИНЖЕНЕРНЫЙ РАСЧЕТ ✅**
**Было:** w_g = W - 100 (упрощенно)
**Стало:** По толщине системы профиля!

```python
SYSTEM_OFFSETS = {
    "ALG 2030-73C": 73,  # → W-146, H-146
    "ALG 2030-63C": 63,  # → W-126, H-126
    "ALG 2030-55C": 55,  # → W-110, H-110
    "ALG 2030-45C": 45   # → W-90, H-90
}

w_g = W - (offset * 2)
h_g = H - (offset * 2)
```

**Формула:** Световой проем = Габарит - Толщина профиля × 2

---

### **5. Импосты - АВТОМАТИЧЕСКИЙ РАСЧЕТ ✅**
**Было:** Ручной ввод длины
**Стало:** Автоматический расчет + опция ручного ввода!

```python
# Вертикальный импост:
impost_length = H - (offset * 2)

# Горизонтальный импост (ТОР):
impost_length = W - (offset * 2)
```

**В интерфейсе:**
- ☑️ Автоматический расчет (рекомендуется)
- Галочки: Левый / Центральный / Правый / ТОР
- Показываются рассчитанные длины
- ИЛИ ручной ввод для нестандартных конструкций
